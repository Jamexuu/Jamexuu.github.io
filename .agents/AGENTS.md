Create a modern, distinctive personal portfolio website for me using **React + TypeScript**.

## My Identity

Role: **Student Software Engineer**

I am an Information Technology student who enjoys building software, learning new technologies, and turning ideas into working applications.

The website should feel like the portfolio of someone who is **actively becoming a software engineer**, not an established corporate developer.

Do NOT make it look like a generic developer portfolio.

---

## Design Direction

Create a UI that is:

* Modern
* Minimal
* Professional
* Slightly experimental
* Calm and refined
* Technical without looking overly "techy"
* Visually interesting without being flashy
* Easy to navigate
* Strong typography and spacing
* Lots of intentional whitespace

Avoid excessive gradients, glowing effects, glassmorphism everywhere, excessive animations, giant text, and overused developer portfolio layouts.

I want something that feels **designed**, rather than a collection of UI components.

Think of the visual language as a combination of:

**editorial design + modern software product UI + personal journal + engineering portfolio**

The design should have a strong visual identity while remaining practical and readable.

---

## Color Direction

Do NOT use the typical:

* Purple + blue gradient
* Black + neon green
* Cyberpunk colors
* Excessive dark-mode glow

Instead, create a sophisticated and slightly unusual color palette.

Use a mostly neutral base such as:

* warm off-white / soft gray
* charcoal
* muted secondary colors

Then introduce **one distinctive accent color** sparingly.

The accent should feel intentional and recognizable, almost like a personal brand color.

The overall website should look good in both light and dark environments if possible, but prioritize the primary theme first.

---

## Typography

Use typography as one of the major design elements.

Use a clean modern sans-serif font such as:

* Inter
* Geist
* Manrope
* Plus Jakarta Sans

You may combine it with a subtle monospace font for technical details such as:

`01 / PROJECTS`

`React · TypeScript`

`student-software-engineer`

Do not overuse monospace fonts.

Typography should create hierarchy through:

* font size
* weight
* spacing
* alignment

rather than decorative effects.

# Website Concept

Instead of a traditional portfolio layout, create a **"Personal Engineering Desk"** concept.

The website should feel like visitors are exploring a carefully organized snapshot of my work and learning journey.

The homepage can contain sections that feel like different pieces of an engineer's workspace rather than traditional portfolio sections.

For example:

### Intro

A restrained introduction:

"Hi, I'm James."

"Student Software Engineer building things, learning constantly, and figuring out how software works."

Include a subtle status indicator such as:

`● Currently learning & building`

Do not make the hero excessively large.

---

Present projects as **case-study-like entries**, not generic project cards.

Each project should communicate:

* Project name
* Short description
* Technologies
* My role
* What problem it solves
* GitHub / Live Demo

Instead of displaying 6–12 cards in a grid, make the projects feel more editorial.

Possible layout:

Project Name
Short description
React · TypeScript · Laravel

---

PROJECT 02
Project Name

PHP · MySQL · Java

Each project can have subtle hover interactions.

### Learning / Journey

Since I am a student software engineer, make the learning process part of the identity.

Create a section called something like:

`CURRENTLY EXPLORING`

Show technologies, concepts, or areas I am learning.

The design should communicate that the portfolio is **evolving with me**.

This is important: do not pretend that I am a senior developer.

---

### About

Keep the About section personal but concise.

It should communicate:

* IT student
* Interested in software development
* Started programming during senior high school
* Enjoys building projects
* Currently developing skills through school and personal projects
* Wants to become a professional software engineer

Avoid corporate-sounding descriptions like:

"I am a passionate results-driven developer dedicated to delivering innovative solutions."

Make it sound like a real student developer.

`WORK`
`ABOUT`
`STACK`

`GITHUB ↗`

Keep it small and elegant.

# Visual Details

Use subtle details to make the design unique:

* thin divider lines
* tiny labels
* project numbering
* subtle grid/background structure
* asymmetric layouts
* editorial spacing
* small technical metadata
* understated hover states
* subtle cursor interactions
* occasional monospace labels

Use asymmetry where appropriate.

Do NOT make every section a centered container with identical cards.

---

# Animations

Animations should be subtle and purposeful.

Use:

* gentle entrance animations
* smooth scrolling
* subtle hover transitions
* slight image movement
* understated text transitions

Avoid:

* excessive parallax
* spinning elements
* constant floating animations
* huge page transitions
* distracting 3D effects

The website should still feel excellent with animations disabled.

---

# Responsive Design

The website must work beautifully on:

* Desktop
* Laptop
* Tablet
* Mobile

On mobile, simplify complex layouts rather than simply shrinking the desktop version.

Typography, spacing, navigation, and project layouts should be intentionally redesigned for smaller screens.

DO NOT create:

* Generic developer portfolio
* Huge "Hello World" hero
* Giant gradient text
* Excessive glassmorphism
* Skill progress bars
* Fake testimonials
* Fake client logos
* Fake statistics such as "50+ projects"
* Stock photos of developers
* Generic coding illustrations
* Excessive glowing effects
* Overly futuristic UI
* Template-looking cards everywhere

The website should feel **personal, intentional, and believable for a student software engineer**.

Not:

"This is another AI-generated developer portfolio."

Prioritize **layout, typography, spacing, composition, and content hierarchy** over decorative effects.
